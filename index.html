Всё, что нужно разработчику.

Знакомый интерфейс и мощные возможности, ничего лишнего.

Бесплатно навсегда

Автоматически выбирается бесплатная модель opencode. Ключи API не нужны.

Работает с проектом

Выбери папку, и агент сам читает и правит файлы прямо в ней.

Чаты с контекстом

История сохраняется. Продолжай диалог после перезапуска, ищи по чатам.

Файлы и подсветка

Дерево проекта, просмотр кода с подсветкой, упоминание файла через @.

Diff изменений

Смотри, что именно изменил агент: цветной diff из git по каждому файлу.

Тёмная тема

Чёрный интерфейс с мягким свечением. Есть и светлая тема, если захочется.

Три шага.

От идеи до готового кода за пару минут.

Выбери папку

Укажи проект, с которым будет работать агент.

Опиши задачу

Обычным языком, как коллеге. Можно упомянуть файлы через @.

Получи результат

Агент напишет код и внесёт правки. Проверь их во вкладке «Изменения».

Установка за минуту.

Нужны Python 3.10+ и Node.js. Или скачай готовый exe со страницы релизов.

$ npm i -g opencode-ai
$ pip install pywebview
$ python main.py
